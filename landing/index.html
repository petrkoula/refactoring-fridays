The evidence loop

Before the edit. After the change.

AI can write code quickly. RefactoringFridays makes the change measurable, explainable, and verifiable.

01

Measure

Inspect complexity, churn, coverage, dependencies, and API impact.

02

Baseline

Record the current state before an agent touches existing code.

03

Plan

Require a proportionate plan when the target is risky.

04

Verify

Run tests, re-measure, and report what actually changed.

A different layer

Not another code reviewer.

Rider refactors. SonarQube measures. PR reviewers inspect the result. RefactoringFridays controls the evidence between an agent’s intention and its code change.

“No baseline, no risky edit.
No verification, no done.”
